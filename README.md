# Ganesh Reddy Yaramala — Portfolio

A modern, responsive personal portfolio for **Ganesh Reddy Yaramala**, a Computer Science student specializing in Artificial Intelligence and Machine Learning. The site presents his interests in full-stack development, intelligent systems, and practical software projects through a polished, recruiter-friendly interface.

## About Me

I am an undergraduate Computer Science student focused on Artificial Intelligence and Machine Learning. I am also passionate about full-stack development and enjoy building clean, maintainable applications that address real-world problems.

The portfolio highlights my technical learning areas, academic and personal projects, and interest in internship opportunities involving full-stack development and AI/ML engineering.

## Technologies Used

- **HTML5** — semantic page structure and accessible content
- **CSS3** — responsive layout, design system, animations, transitions, light/dark themes, and visual styling
- **Vanilla JavaScript** — interactivity without external frameworks or dependencies
- **Browser APIs** — `localStorage`, `matchMedia`, `IntersectionObserver`, and DOM events

## Features

- Responsive single-page layout with Home, About, Skills, Projects, and Contact sections
- Sticky navigation with a mobile menu toggle
- Smooth scrolling and active navigation state based on the visible section
- Light/dark theme toggle with saved preference and system-theme support
- Hero section with developer snapshot visual
- Skills grouped into programming, web development, and AI/ML learning areas
- Project cards for:
  - Smart Crop Recommendation System
  - MacroSnap
  - SmartFarmAI
- Client-side contact-form validation with inline feedback
- Friendly notifications for project links that are not yet available
- Dynamic copyright year in the footer
- GitHub and LinkedIn profile links

> **Note:** The contact form currently provides browser-side validation and success feedback only; it is not connected to a backend email service. Project repository and demo links are marked as pending in the portfolio until valid URLs are available.

## Installation and Usage

This is a static website and does not require a build step, package manager, or external dependencies.

### Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/YaramalaGaneshReddy/Ganesh_Portfolio.git
   ```

2. Open the project directory:

   ```bash
   cd Ganesh_Portfolio
   ```

3. Open `index.html` in a modern web browser.

For the best local development experience, serve the folder with any static-file server and open the provided local URL.
