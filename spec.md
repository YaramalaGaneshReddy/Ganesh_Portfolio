The project folder and files have already been created.


* Vanilla JavaScript

### 6. Responsive Design

The website must work correctly at these screen widths:

Mobile: 375px
Tablet: 768px
Desktop: 1280px and above

Requirements:

* Mobile-first responsive CSS.
* No horizontal scrolling.
* Navigation must work on mobile.
* Project cards must adapt to different screen sizes.
* Text must remain readable.
* Buttons must be easy to click.
* Images and visual elements must fit their containers.

Use CSS Flexbox and Grid where appropriate.

### 7. JavaScript Functionality

Implement the following interactions using vanilla JavaScript:

1. Mobile navigation toggle.
2. Dark mode toggle with a persistent preference using localStorage.
3. Smooth scrolling.
4. Active navigation state where appropriate.

Ensure JavaScript is clean and understandable.

### 8. Code Quality

Follow these requirements:

* Use semantic HTML elements.
* Use meaningful class names.
* Avoid unnecessary div elements.
* Keep HTML, CSS, and JavaScript separated.
* Add comments only where helpful.
* Avoid duplicate code.
* Avoid unnecessary complexity.
* No JavaScript console errors.
* No broken links or images.
* No unnecessary external dependencies.

### 9. Development Workflow

Before making changes:

1. Inspect the existing index.html, style.css, and script.js.
2. Understand the existing project structure.
3. Preserve useful existing code.
4. Implement the website in the appropriate files.
5. Verify that all files are correctly connected.

Do not simply generate the website without checking the existing files.

### 10. Testing and Verification

After implementation:

* Verify all navigation links.
* Verify mobile navigation.
* Verify dark mode.
* Verify all project cards.
* Check the console for errors.
* Check for broken links.
* Test at 375px, 768px, and 1280px widths.
* Verify that CSS and JavaScript load correctly.

If browser testing is available, use it to inspect the actual website and fix any problems.
